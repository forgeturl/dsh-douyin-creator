# 抖音脚本审查

保留用户原有定位、结构和口吻，只修改会影响真实性、理解、留存或合规的内容。若脚本有正文、字幕、封面和分镜，要同步检查全部可见文本。

## 工作流

1. 标记平台机制主张、外部事实、数字、预测、因果和结果承诺。
2. 平台机制用 `douyin_official_search` 核对 2 至 5 份相关原文。
3. 新闻、财经、人物或企业事实必须查一手材料；本插件的抖音资料不能替代企业公告、财报、监管文件或政府通报。
4. 对每个数字核对主体、时间、统计口径、分母、币种和来源。
5. 将事实、观点和预测分开；未完整披露的事实降低断言强度。
6. 返回可直接替换的文案，并说明改动理由和剩余不确定性。

## 输出边界

前两秒优先交代主体、冲突和价值，但不能用虚假数据或确定性结果诱导。不得承诺播放、涨粉、收益、投资结果或平台选择结果。

官方视频转写只能补充证据；关键数字、否定词和规则边界需要正式文本或回听复核。涉及当前政策时继续核对最新官方网页。

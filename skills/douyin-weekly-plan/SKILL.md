# 抖音一周实验计划

周计划的目标是学习并缩小不确定性，不是保证播放或涨粉。先确认赛道、目标受众、账号阶段、可用产能和近期作品基线。

## 工作流

1. 用 `douyin_official_search` 核对计划依赖的推荐、搜索、内容质量和治理机制。
2. 选 1 个主假设和最多 2 个次假设，例如首帧承诺、搜索意图或内容结构。
3. 安排可完成的作品数量；同一轮实验尽量只改变一个关键变量。
4. 每条作品写明目标受众、用户问题、首帧、交付价值、证据来源和行动引导。
5. 提前定义观察指标、账号基线、复盘时间和停止条件。
6. 周末输出“保留、修改、停止”三类决策，并记录证据，而不是凭感觉续做。

## 输出格式

先给一周目标和假设，再给每日任务，最后给指标表和复盘规则。平台官方依据、运营假设和账号结论必须分层。

不得承诺涨粉、播放或收益，不给所有账号通用的最佳发布时间。发布时间应根据受众在线数据和账号历史做分时实验。
